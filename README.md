# CustomerKart

CustomerKart is an e-commerce application designed to provide customers with an easy and convenient platform to browse products, manage their shopping cart, place orders, and make payments.

## Features

- Customer registration and login
- Product browsing
- Product categories
- Shopping cart management
- Order management
- Payment processing
- Customer reviews
- Notifications

## Technologies Used

- Python
- SQL
- Flask
- HTML
- CSS
- JavaScript

## Project Structure

- `app.py` – Main application
- `main.py` – Application logic
- `buyers_table.sql` – Buyers database table
- `cart_table.sql` – Cart database table
- `categories_table.sql` – Categories database table
- `order_table.sql` – Orders database table
- `payments_table.sql` – Payments database table
- `products_table.sql` – Products database table
- `reviews_table.sql` – Reviews database table
- `sellers_table.sql` – Sellers database table

## Purpose

The purpose of CustomerKart is to provide a simple and organized e-commerce system for managing customers, products, shopping carts, orders, payments, and reviews.
